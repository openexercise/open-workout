# Security

Please don't report a security problem in a public issue.

Report it privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability**. If you can't use GitHub, write to maintainers@openexercise.org.

We'll acknowledge it within 5 working days, keep you told of progress, and credit you in the fix unless you'd rather not be named.

This covers the code in this repository: the tools, the libraries and the website it builds. For a problem in Lifterclub itself, the reference application, write to privacy@lifterclub.com.
