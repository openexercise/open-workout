Your training, in a format you can take anywhere.

The Open Workout Schema records what someone did: a workout, its exercises and sets, where the record came from, and which numbers were inferred. Any app can write it, any assistant can read it, and the person keeps the log.

Read the schemaSee the MCP tools

Honest numbers

A set holds what the person stated, in the unit they gave. Anything inferred is listed in estimates by JSON pointer, so a number's standing travels with it.

Provenance on every record

source says which app or assistant wrote it and the record's ID there; merged_sources keeps both when two apps describe the same session.

One language for exercises

Each entry names its exercise by an Open Exercise ID and says whether the match is sure, close, the person's own, or unmatched.
